# MONSOONAI — Streamlit Dashboard (Phase 4)

Mumbai next-day rainfall intelligence, built on the validated Phase 2
data and the evaluated Phase 3 models. Six pages: Overview, Rainfall
Prediction, Historical Analysis, Extreme Rainfall, Model Performance,
Data & Methodology.

## What it is — and is not

- **It is** an educational / research dashboard showing measured,
  historical results for one Mumbai reanalysis grid cell, 2000–2024.
- **It is not** a live forecast, a weather service, or a warning
  system. Heavy-rain prediction is unreliable and the dashboard says
  so prominently. All metrics are against Open-Meteo / ERA5
  reanalysis, not rain-gauge observations.

## Run locally

```bash
# 1. Python 3.12, project virtual environment
python3 -m venv ~/workspace/monsoonai-venv
source ~/workspace/monsoonai-venv/bin/activate

# 2. Install dependencies (pinned versions)
pip install -r app/requirements.txt

# 3. From the project root, start the dashboard
streamlit run app/app.py
```

Then open the URL Streamlit prints (usually http://localhost:8501).

## How the dashboard gets its numbers

- Regression metrics are read from `artifacts/evaluation_summary.json`
  (Phase 3 output, unedited).
- Classification metrics, feature importances and year-wise results
  are **recomputed at startup from the saved model artefacts** with
  the same logic as `src/evaluate_models.py` — they are never typed
  into the app by hand.
- Predictions on the Rainfall Prediction page are generated by the
  saved joblib models from the local processed dataset
  (`data/processed/mumbai_daily_2000-2024.csv`), using only data dated
  t or earlier. No live weather feed is connected.
- If a required data or model file is missing, the app shows a clear
  error instead of inventing a substitute.

## Structure

```
app/
  app.py              Entry point + navigation + theme
  data_loader.py      Loads data/artefacts; recomputes derived metrics
  feature_engine.py   Reuses src/features.py (no duplicated definitions)
  predict.py          Next-day prediction from the saved artefacts
  charts.py           Consistent Plotly styling
  ui_common.py        Category legend, warning/info boxes, footer
  views/              One module per page (overview, prediction,
                      historical, extreme, performance, methodology)
                      — named "views" (not "pages") so Streamlit does
                      not auto-discover it as multipage navigation
  requirements.txt    Pinned dependencies
  .streamlit/         Dark navy theme
```

## Reproduce the models

```bash
~/workspace/monsoonai-venv/bin/python src/train_models.py
~/workspace/monsoonai-venv/bin/python src/evaluate_models.py
```
