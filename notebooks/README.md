# Notebooks

This folder is intentionally empty for now.

Exploratory data analysis for MONSOONAI lives in the written
documentation, not in notebooks:

- `docs/data-quality-note.md` — measured data quality (row counts,
  missing values, rainfall summaries, the corrected three-way
  classification).
- `docs/crosscheck-and-threshold.md` — the IMD vs Open-Meteo
  comparison and the verified rainy-day threshold.
- `docs/model-evaluation-report.md` — full model evaluation with
  plots in `docs/figures/`.

If exploratory notebooks are added later, they should be short,
readable, and reproducible from `data/processed/` — and they must
not contain results that contradict the evaluation report.
